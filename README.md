# 綴 Tsuzuri — ブラウザで動くジャーナリングアプリ

ビルド不要・依存ライブラリなし。データはすべて**あなたのブラウザの中だけ**（IndexedDB）に保存され、外部には一切送信されません。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。GitHub Pages などの静的ホスティングにそのまま置くこともできます（暗号化と Service Worker は HTTPS または localhost で動作します）。

## 主な機能

| 分類 | 機能 |
| --- | --- |
| ✍️ 書く | Markdown エディタ（書く / 分割 / プレビュー）、自動保存、リスト自動継続、Tab でインデント、プレビュー上でチェックボックスを切替、URL 貼り付けでリンク化、集中モード |
| 🧭 習慣化 | 日替わりのお題（30種）、テンプレート8種（デイリー・感謝日記・モーニングページ・KPT・週次レビューなど）、1日の目標文字数、連続記録（ストリーク） |
| 🏷️ 整理 | 気分（5段階）、タグ、お気に入り、全文検索（`#タグ` 指定・複数語 AND）、気分やお気に入りでの絞り込み |
| 📅 振り返り | 気分で色分けされたカレンダー、「1週間前・1か月前・過去の今日」、ランダムに読む |
| 📈 インサイト | 1年間のヒートマップ、30日間の気分推移、気分の分布、曜日別・時間帯別の傾向、タグと気分の関係、よく使う言葉 |
| 🔒 プライバシー | パスフレーズによる AES-GCM 256bit 暗号化（PBKDF2-SHA256 31万回）、ロック画面、自動ロック、暗号化バックアップ |
| 💾 データ | JSON / Markdown 書き出し、JSON 読み込み（更新日時でマージ）、エントリー単位の書き出し・印刷・複製 |
| 📱 その他 | オフライン動作（PWA）、ホーム画面へのインストール、ライト / ダーク / セピアテーマ、ゴシック / 明朝 / 等幅、スマホ対応 |

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| Ctrl/⌘ + N | 新しく書く |
| Ctrl/⌘ + K | 検索 |
| Ctrl/⌘ + S | 今すぐ保存 |
| Ctrl/⌘ + E | プレビュー切替 |
| Ctrl/⌘ + B / I | 太字 / 斜体 |
| Ctrl/⌘ + Shift + F | 集中モード |
| Ctrl/⌘ + Shift + L | ロック（暗号化時） |

## 構成

```
index.html            画面の骨組み
css/style.css         スタイル（テーマ・レスポンシブ・印刷）
js/app.js             画面・エディタ・統計・設定
js/db.js              IndexedDB ラッパー
js/crypto.js          Web Crypto による暗号化
js/markdown.js        安全な軽量 Markdown レンダラー（HTML は常にエスケープ）
js/data.js            気分・お題・テンプレート
sw.js                 オフライン用 Service Worker
manifest.webmanifest  PWA マニフェスト
```

## 注意

- データはブラウザごと・端末ごとに保存されます。ブラウザのサイトデータを消すと記録も消えるため、定期的にバックアップしてください。
- 暗号化のパスフレーズを忘れると復元できません。
