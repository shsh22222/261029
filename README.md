# 綴 Tsuzuri — こころのジャーナル

ビルド不要・依存ライブラリなし。データはすべて**あなたのブラウザの中だけ**（IndexedDB）に保存され、外部には一切送信されません。

## 公開（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を「**Deploy from a branch**」にする
3. **Branch** で `claude/amazing-allen-jot0ah`（または `main`）と `/ (root)` を選んで **Save**
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける（以後は push するたびに自動更新）

> サーバーは使いません。記録は各端末のブラウザ内（IndexedDB）に保存され、外部には送信されません。PC とスマホの記録は自動では同期されないため、設定の「書き出し／読み込み」で移せます。

ローカルで試す場合：`python3 -m http.server 8000` → http://localhost:8000

## こころのジャーナル（研究ベース）

短い問いに答えていくだけで、気持ちを整え、毎日の中のよいことに気づけるように設計しています。

| 問い | 時間 | 内容 | 主な根拠 |
| --- | --- | --- | --- |
| 🌅 朝のひととき | 2分 | 今の気持ち → 今日大切にしたいこと → 小さな楽しみ | 価値の確認、セイバリング、感情のラベリング |
| ✏️ ひとこと | 1分 | よかった・しんどい・感謝・気づきをいつでも | セイバリング、感情のラベリング |
| 🌙 夜のふりかえり | 3分 | よかったこと3つ → 親切 → 心に残ったこと → 気がかりを置いていく | Three Good Things、親切を数える、書き出し |
| 🫧 こころのケア | 3分 | 何があった → 気持ちに名前 → 友人にかける言葉を自分に | セルフ・コンパッション、自己距離化 |
| 📝 書き出す | 15分 | タイマー付きで自由に書く | エクスプレッシブ・ライティング |
| 🌱 未来の自分 | 10分 | うまくいった数年後の一日を描く | ベスト・ポッシブル・セルフ |
| 🍃 週のふりかえり | 5分 | 1週間のよかったことを読み返す | セイバリング |

- ホームには、時間帯に合わせた「いまのおすすめ」をひとつだけ表示します
- しんどい記録があった日は、こころのケアをそっと提案します
- 各問いのあとに「続けて自由に書く」ことができます
- 過去の記録は読みやすいページで開き、「編集」で書き直せます
- 1週間以上前の「よかったこと」を日替わりでひとつ思い出させます
- 連続日数ではなく「今月何日書いたか」を表示し、途切れても負担にならないようにしています
- しんどい日が続いたときは、相談窓口を案内します
- 設定から朝・夜のリマインダーをカレンダーに登録できます

## 主な機能

| 分類 | 機能 |
| --- | --- |
| ✍️ 書く | Markdown エディタ（書く / 分割 / プレビュー）、自動保存、リスト自動継続、Tab でインデント、プレビュー上でチェックボックスを切替、URL 貼り付けでリンク化、集中モード |
| 🧭 習慣化 | 日替わりのお題（30種）、テンプレート8種（デイリー・感謝日記・モーニングページ・KPT・週次レビューなど）、1日の目標文字数、連続記録（ストリーク） |
| 🏷️ 整理 | 気分（5段階）、タグ、お気に入り、全文検索（`#タグ` 指定・複数語 AND）、気分やお気に入りでの絞り込み |
| 📅 振り返り | 気分で色分けされたカレンダー、「1週間前・1か月前・過去の今日」、ランダムに読む |
| 📈 インサイト | 1年間のヒートマップ、30日間の気分推移、気分の分布、曜日別・時間帯別の傾向、タグと気分の関係、よく使う言葉 |
| 🔒 プライバシー | パスフレーズによる AES-GCM 256bit 暗号化（PBKDF2-SHA256 31万回）、ロック画面、自動ロック、暗号化バックアップ |
| 💾 データ | JSON / Markdown 書き出し、JSON 読み込み（更新日時でマージ）、エントリー単位の書き出し・印刷・複製 |
| 📱 その他 | オフライン動作（PWA）、ホーム画面へのインストール、ライト / ダーク / セピアテーマ、ゴシック / 明朝 / 等幅、スマホ対応 |

## 構成

```
index.html            画面の骨組み
css/style.css         スタイル（テーマ・レスポンシブ・印刷）
js/app.js             画面・エディタ・統計・設定
js/db.js              IndexedDB ラッパー
js/crypto.js          Web Crypto による暗号化
js/markdown.js        安全な軽量 Markdown レンダラー（HTML は常にエスケープ）
js/data.js            気分・お題・テンプレート
sw.js                 オフライン用 Service Worker
manifest.webmanifest  PWA マニフェスト
```

## 注意

- データはブラウザごと・端末ごとに保存されます。ブラウザのサイトデータを消すと記録も消えるため、定期的にバックアップしてください。
- 暗号化のパスフレーズを忘れると復元できません。
